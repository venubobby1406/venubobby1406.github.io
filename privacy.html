Privacy

Draft — have this reviewed before you rely on it. The parts marked in square brackets need a real answer before publication.

What we collect: nothing.

This site is static files on a static host. There is no database behind it, no account to create and no upload endpoint — so there is nothing to collect.

01 — The short version

If you only read one part, read this one.

No cookies, no trackers, no pixels

Nothing on this site sets a cookie, runs analytics, loads a tracking pixel or calls a third party. There is no CDN, no web font service and no remote script. The page you are reading is the whole page.

Nothing stored about you

No account, no email, no sign-up

There is nowhere to create an account and no form that sends anything anywhere. If a future version adds one, it will say so on this page first.

No identity required

Your recordings never leave your machine

Recording, trimming and converting all happen in your browser, through APIs your operating system already exposes. The file is written by your browser to your disk. No part of it is transmitted to us, because there is nowhere for it to go.

0 KB uploaded

02 — The details

What the site stores on your own device, and what a host sees.

Two keys in your browser's local storage

If you paste a Pro licence key, it is kept in your browser's local storage so the page can show you are signed in. If you move the camera bubble, its size and position are kept the same way. Both stay on your device. Clearing site data removes them.

Local only

What the host can see

Our host serves the page files. Like any web host, it can see the requests people makes — an IP address, a browser, a timestamp. We do not add anything to those requests: no identifiers, no user agents of our own, no logging on the site itself.

Host access only

The one outbound request

If you press Share and ask for a link, the clip is sent to the storage service that holds shared links — the only time this site puts a file on a server. That service deletes clips on a set expiry, and you can delete one yourself with the button on the link. It is opt-in, every time.

Opt-in only
