06 — Straight answers

Questions, answered straight.

If something here is wrong, tell us and we will fix it.

Does my recording get uploaded anywhere?

No. Recording uses the screen-capture API your OS already exposes, and the file is written straight to your downloads folder. No server, so no upload bar and no wait.

Do I need an account?

No, and there is no plan where you do. Every tool opens and works immediately.

Which browsers work?

Chrome and Edge are the smoothest. Firefox records screen and microphone; system audio depends on the browser. Safari runs the file tools.

Is there a watermark?

No logo, no caption, no “made with” line, no upgrade prompt at export.

How long can a recording be?

As long as you like, with pause and resume. The practical limit is your disk and your tab.

Can I share a link like the other tools?

Not yet, and we would rather say so than fake it. A link means somebody holds the file, so it needs storage and an account. The code is written and tested — button, upload, seven-day expiry, delete token — and waits on one free Cloudflare account. Until then, “Download” and “Send to an app” are the honest words.
