06 — Straight answers

Questions, answered straight.

If something here is wrong, tell us and we will fix the page and this list at the same time.

Does my recording get uploaded anywhere?

No. Recording happens in your browser through the same screen-capture API your operating system already exposes, and the file is written straight to your downloads folder. There is no server to upload to, which is also why there is no upload bar and no processing wait.

Do I need an account?

No, and there is no plan where you do. Every tool — the recorder, the trimmer, the converters — opens and works immediately.

Which browsers work?

Chrome, Edge and other Chromium browsers are the smoothest, and they are the ones that can capture a window or a single tab. Firefox records the screen and the microphone, but exposes fewer sources. Safari runs the file tools; screen capture there is limited.

Is there a watermark?

No. No logo, no caption, no “made with” line, and no upgrade prompt when you hit export.

How long can a recording be?

As long as you like, with pause and resume — there is no timer. The honest limit is your machine: the clip is built in memory while you record, so an hour with the camera bubble is comfortable and a very long take on a small laptop can exhaust the tab.

Can I share a link like the other tools?

Not yet, and we would rather say so than fake it. A link means somebody holds the file, so it needs storage and an account to hold it. The code for it is written and tested — the button, the upload, the seven-day expiry, the delete token — and it is waiting on one free storage account. Until then, “Download” and “Send to an app” are the honest words, and the file stays on your machine.
